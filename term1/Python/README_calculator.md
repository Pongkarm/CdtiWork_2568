# Modern Calculator with Tkinter

A beautiful and functional calculator built with Python and Tkinter.

## Features

- **Basic Operations**: Addition (+), Subtraction (-), Multiplication (×), Division (÷)
- **Advanced Functions**: Square root (√), Square (x²), Reciprocal (1/x), Percentage (%)
- **Utility Functions**: Clear (C), Backspace (⌫), Sign change (±)
- **Modern UI**: Dark theme with hover effects and responsive design
- **Error Handling**: Prevents division by zero and invalid operations

## How to Run

1. Make sure you have Python installed on your system
2. Navigate to the Python directory
3. Run the calculator:
   ```bash
   python calculator_tk.py
   ```

## Usage

### Basic Operations
1. Click number buttons to input values
2. Click operation buttons (+, -, ×, ÷) to perform calculations
3. Click "=" to see the result

### Advanced Functions
- **√**: Calculates the square root of the current number
- **x²**: Squares the current number
- **1/x**: Calculates the reciprocal (1 divided by the current number)
- **%**: Converts the current number to percentage (divides by 100)

### Utility Functions
- **C**: Clears the calculator and resets to 0
- **⌫**: Removes the last entered digit
- **±**: Changes the sign of the current number (positive/negative)

## Interface

The calculator features a modern dark theme with:
- Large, easy-to-read display
- Color-coded buttons:
  - Gray: Numbers and decimal point
  - Orange: Basic operations
  - Red: Clear function
  - Purple: Advanced mathematical functions
  - Light gray: Utility functions
- Hover effects for better user experience
- Responsive grid layout

## Requirements

- Python 3.x
- Tkinter (usually comes with Python installation)
